#  Sistema Web Qorichaska - Gestión de Inventario y Ventas

Repositorio para la modernización tecnológica de Tejidos Qorichaska.

##  Tecnologías y Arquitectura
- **Backend:** Java 17 + Spring Boot
- **Base de Datos:** MySQL (Modelo Relacional 3FN)
- **Patrón:** POO y JPA Entities
